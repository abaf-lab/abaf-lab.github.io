Troubleshooting: Reports Won't Export

Applies to Acme Analytics web app, all plans
Last reviewed [date]
Owner [team]

Sample document. This guide is written for a fictional product (“Acme Analytics”) to demonstrate structure, tone, and troubleshooting design.

Symptom

You select Export on a report, but no file downloads, or you see the message “Export failed.”

Before you start

  • You need Viewer access or higher on the report.
  • Exports are limited to 100,000 rows per file.

Quick checks

  1. Confirm the report finished loading.
  2. Try a different export format (CSV instead of XLSX).
  3. Open the report in a private browser window to rule out extensions.

Causes and fixes

CauseHow to tellFix
Report exceeds the row limitBanner reads “Too many rows”Add a filter or date range, then export again
Browser is blocking downloadsNo prompt appears; download icon shows a blockAllow downloads for the Acme domain in browser settings
Missing permissionExport button is disabledAsk the report owner for Viewer access or higher
Temporary service issueError persists across browsers and reportsCheck the status page, then try again later

If the problem continues

Contact support and include:

  • The report name and URL
  • The export format you chose
  • The exact error message
  • Your browser and version
